# WeeWX extensions installed via `weectl extension install` at build time.
# One URL per line; `#` lines and blank lines are ignored by
# install_extensions.sh. Pinned to specific commits or release tags so
# renovate can track them.
#
# Each URL is preceded by one or more `# install: <path>` lines. Those
# lines are comments to install_extensions.sh but are read by
# build/check_image.sh to assert that the install actually produced the
# expected files. Drop or rename a `# install:` line whenever the URL's
# install behaviour changes; the in-image assertion then tracks the new
# layout without a separate edit to check_image.sh.
#
# Paths are relative to /opt/weewx-data/ - typically:
#   bin/user/<module>.py    a python module under user/
#   skins/<name>            a skin directory
#
# Realtime-gauge-data is NOT here: its install.py uses distutils + the
# old WeeWX 3/4 ExtensionInstaller API, so weectl can't install it.
# See build/install_rtgd.py for the manual unpack.
